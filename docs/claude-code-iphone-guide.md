# iPhoneアプリ版 Claude Code 利用ガイド（Q&Aまとめ）

作成日：2026-10-04

## 要点

1. **iPhoneアプリはクラウド上の作業環境を動かすリモコン。** クラウド内の作業ならほぼすべて実行できる。
2. **PCのファイルやアプリは、そのままでは操作できない。** Remote Control を使えば操作できるが、PCが起動していることが条件。
3. **プッシュ＝GitHub への保存。** クラウドの作業環境は一時的なので、残したいものはプッシュする。

---

## Q1. iPhoneアプリの Code はどこまで操作できるか？

### できること（クラウドの作業環境で実行）

| 分類 | 内容 |
|---|---|
| コード作業 | リポジトリ `debikaru/rep` の閲覧・編集、Python等の実行、テスト、コミット、プッシュ |
| GitHub | ブランチ作成、PR作成・レビュー対応、Issue操作、CI結果の確認 |
| 接続済みサービス | Gmail、Googleカレンダー、Googleドライブ、TradingView |
| 成果物の作成 | HTMLページ（Artifact）、Docs、Excel・PDF・PowerPoint |
| 定期実行・通知 | 定期タスク（Routine）、リマインド、PRの監視 |
| ネット接続 | 環境のネットワーク設定で許可されたサイトのみ |

### できないこと・注意点

| 項目 | 内容 | 対処法 |
|---|---|---|
| PC内のファイル・アプリ | クラウドとPCはつながっていない | Remote Control を設定する |
| iPhone本体の操作 | 写真・他のアプリなどは操作できない | 該当なし |
| 他のリポジトリ | 対象は `debikaru/rep` のみ | 依頼すれば追加可能（GitHubの権限が必要） |
| データの保持 | 作業環境は一定時間で消える | コミットしてプッシュする、またはドライブに保存する |
| 送信・削除などの操作 | 外部に影響する | 実行前に Claude が確認を取る |

### 使い方のポイント

- 長い作業は指示を出したらアプリを閉じてよい。クラウドで作業は続き、完了通知も設定できる。
- プロジェクトの仕様書は `CLAUDE.md` としてリポジトリに置く。毎回自動で読み込まれ、前提のズレを防げる（`/init` で雛形を作成できる）。

## Q2. Remote Control でも、PCは起動していないとダメか？

**ダメ（起動が必要）。** 次の3つがすべて揃っている必要がある。

1. PCの電源が入っていて、スリープしていない
2. インターネットにつながっている
3. Claude Desktop アプリ、またはターミナルの `claude remote-control` が起動したまま

### 画面ロックについて

| 作業の種類 | ロック中に動くか | 例 |
|---|---|---|
| ファイル操作・スクリプト実行 | 基本的に動く | Pythonの実行、ファイル整理 |
| 画面を操作する作業（computer use） | 動かない可能性が高い（要検証） | Kindle for PC のキャプチャ |

### Windowsでのおすすめ設定

- スリープを「なし」にする：設定 → システム → 電源 → 画面とスリープ
- ノートPCの場合：電源につないだうえで、「カバーを閉じたときの動作」を「何もしない」にする
- 使い分け：PCが不要な作業はクラウドで行う。PCは Kindle のようにPCでしかできない作業のときだけ起動しておく。

## Q3. プッシュするとデータはどこに保存されるか？

**GitHub 上のリポジトリ `debikaru/rep` に保存される。**

| 段階 | 操作 | 保存場所 | 消えるか |
|---|---|---|---|
| ① 編集 | ファイルを作る・直す | クラウドの作業環境（一時的） | 消える |
| ② コミット | 変更を記録として確定する | 同じ作業環境の中 | まだ消える |
| ③ プッシュ | 記録を GitHub に送る | GitHub（github.com/debikaru/rep） | 消えない |

例え：コミットは「伝票を書いて手元で締める」こと、プッシュは「その伝票を本店の台帳に記帳する」こと。

### 補足

- ブランチは作業用の別ノート。作業用ブランチへのプッシュは `main` に影響しない。
- iPhoneのブラウザや GitHub アプリからいつでも確認できる。
- リポジトリが Public（公開）の場合は誰でも見られるため、パスワードや個人情報は入れない。
- PDFや資料などコード以外のデータは、Googleドライブに保存する方が向いている。
